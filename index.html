Waiting for MIDI connection...

Make sure your Roland FP-30x is turned on and Bluetooth is enabled on this device. Note: Web MIDI is usually supported in Chrome/Edge.

Troubleshooting:
  • iPhone/iPad users: Standard browsers don't support MIDI. Use an app like Web MIDI Browser.
  • Android/PC users: Ensure you are using Google Chrome or Microsoft Edge.
  • Permissions: Check your browser URL bar (the lock icon 🔒) to ensure MIDI or Bluetooth access isn't blocked.
  • Gemini Preview: If you are viewing this inside the Gemini preview window, hardware access is blocked by default. Use the virtual keyboard below or run this file in a separate browser window.
